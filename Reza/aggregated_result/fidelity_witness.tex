\section{Findings}
\begin{itemize}
    \item we rely on the inequality 
    $$\forall O: ~ F(\rho_t, \rho_p) \ge F(\rho_t, O)^2 + F(O, \rho_p)^2 - 1$$
    \item Using \href{https://doi.org/10.48550/arXiv.2002.08953}{classical shadows framework}, by collecting multiple measurements from $\rho_t$ and $\rho_p$ we can have an estimate of $F(O, \rho)$ for any $O$ as long as $O$ has a simple structure like being a pure separable state.
    
    A classical gradient descend can find us the $O$ that produces a relatively high lower bound for the fidelity.
\end{itemize}
